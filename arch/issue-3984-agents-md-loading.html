AGENTS.md loading is a map today; it can become deterministic by path

OpenHands SDK already treats root AGENTS.md as repository context and this repository uses a root map to point agents at package-level files. SmolPaws has the same shape at a larger scale. The missing piece is a deterministic file-operation trigger that loads applicable nested AGENTS.md files instead of asking the model to remember the map.

4A Codex-style version would make the map executable

ⓘ Codex walks from project root down to current working directory, collects each AGENTS.md, and concatenates them root-to-leaf. Its base prompt says nested files scope to their subtree and deeper files win on conflicts. agents_md.rs:1-16 default.md:17-27

Minimal OpenHands shape: reuse existing project-skill rendering, but key discovery by touched_path at the tool-use seam. Run it for create/write as well as read/edit so new files get scoped guidance before content is finalized.
