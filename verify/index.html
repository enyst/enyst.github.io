Self-Healing Codebase Project

A codebase that can help check and repair itself needs a map of its behavior, a way to drive the real product, and evidence that a fix works. This project builds that loop for the OpenHands app, Agent Server and core SDK. Agents reproduce bugs, propose repairs and verify the result; maintainers make the decisions. The map then describes the application as it works now.
