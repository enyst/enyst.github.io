F22 Creating automations: templates, setup and import

29 behaviors · 39 scripts & contracts · Maintained source

Entry points & prerequisites

What this family covers

A user adds an automation in three ways. The Templates sub-page (/automations/templates) lists the prebuilt catalog from @openhands/extensions (6 featured, 17 Beta) with search; picking a card either opens a manifest-driven setup dialog at /automations/new/<id> (prerequisites → form → review → Confirm and create), or first asks where a GitHub/Slack responder should run, or first asks the user to install missing MCP integrations, or seeds a conversation with the entry's launch prompt. Add Automation → Create Automation opens the agent-assisted setup page at /automations/setup, where the form opens before a conversation exists. Saving a server-backed draft and testing its generated custom script need no LLM; sending a prompt starts genuine model assistance through automation_form_update. The setup page's own fields, draft validation, Test and Create each have their own IDs in F28. Add Automation → Import automation reads an exported JSON file, previews it and creates it disabled.

How a user gets here

  • Sidebar Automate (sidebar-automations-link), then Templates in the Automate sub-page nav (automations-navbar-desktop >> automations-navigation-templates; at phone width automations-navbar-mobile). The command menu has no Templates entry (searching template gives No commands found).
  • Direct URLs /automations/templates and /automations/new/<catalog-id> (for example /automations/new/custom-automation, /automations/new/news-digest, /automations/new/qa-changes). A deep link opens the setup dialog over the page; it bypasses the responder and install-queue dialogs that a card click shows first.
  • Template cards elsewhere use the same launcher: the Recommended automations rail on home/New Chat (F03) and on the empty dashboard (F21.empty-rail), and the onboarding say-hello step (F01).
  • Dashboard header Add Automation (automations-add-automation) → Create Automation (automations-add-automation-create) or Import automation (automations-import-automation). The empty dashboard also shows the Create Automation instructions inline (automations-empty >> automations-create-automation).

Given

Preconditions:

  • Baseline state (launched, doctored, onboard --skip done) and control-openhands llm preset deepseek for model/profile-dependent checks. Agent assistance, prompt/plugin Test and Run now use genuine deepseek-flash within the run's authorized model budget. The Open and save a draft, Credential-free script test and Resume at phone width bullets may start on an unconfigured fresh stack without this preset.
