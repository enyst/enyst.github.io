How the matches were checked

This survey covers OpenHands/OpenHands. The open list comes from 315 issues by enyst and 22 by smolpaws, compared with 585 enyst PRs and 24 smolpaws PRs. Exact issue references in PR titles and descriptions were read in context, with issue discussions and targeted PR searches used where needed. Partial implementation counts as a corresponding PR; documentation, QA, bug-filing and explicitly unrelated mentions do not.

The other-author list maps the same 59 open issues to verified corresponding PRs by other accounts. A PR match describes relevant work, rather than completion: drafts, closed proposals, partial fixes and historical fixes remain labeled. The historical fix for #14014 does not establish that the reopened issue is solved.

For the seven-day list, repository issue records were refreshed and filtered by issue author and closure time. Matched PRs were merged immediately before the recorded closures, with explicit fixing or closing references checked. The one partial tracker is separated from solving matches. Counts refer to issues, and each closed issue appears once.

A PR without an issue reference may be missed. “No implementation PR identified” records the search finding. An absent timeline reference alone was not treated as proof. This page is a dated snapshot and does not refresh automatically.
