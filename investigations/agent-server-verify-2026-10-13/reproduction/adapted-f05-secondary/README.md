# F05 secondary branches

These minimal recipes retain the original expected result and `# bug` marker,
but reach assertions that the original multi-assertion bullets did not execute.
The missing-ID interrupt assertion independently returns 400 instead of its
documented 404. The mid-call pause is arranged with the documented hanging
loopback provider fixture; status search and PauseEvent prove acceptance before
the disk snapshot is checked.

No real model or external account is used. The ordinary CLI launches two fresh
servers, records API exchanges and recipe transcripts, and stops each run.
These branches extend existing F05 bugs and add no duplicate counts.

```sh
.venv/bin/python /workspace/verification-artifacts/adapted-f05-secondary/run-adapted-f05-secondary.py map run --file F05 --fresh --repeat 2 --record --keep-going --timeout 120
```
